# Codex Theme Studio v1.4.3

这是面向公开分享整理的版本，重点完善项目首页和 Mac 兼容性。

## 下载

- `Codex-Theme-Studio-macOS-v1.4.3.zip`：Universal 2 原生菜单栏 App
- `create-codex-theme-skill-v1.4.3.zip`：主题搜索与制皮 Skill

## 主要更新

- macOS App 现在同时包含 `arm64` 与 `x86_64`，支持 Apple Silicon 和 Intel Mac
- README 首屏加入最新版下载入口、应用实机截图、核心功能和一分钟安装指南
- 完善 GitHub 仓库简介、主页地址与 Topics
- 保留 v1.4.2 的主题资产刷新、搜索与热切换能力

## 安装

1. 下载并解压 App ZIP。
2. 把 `Codex Theme Studio.app` 移到“应用程序”或 `~/Applications`。
3. 首次打开如被 macOS 拦截，请在 Finder 中右键 App 并选择“打开”。
4. 选择主题并开启皮肤。

公开构建采用 ad-hoc 签名、尚未 Apple 公证。应用不修改官方 Codex App、`app.asar` 或代码签名。
