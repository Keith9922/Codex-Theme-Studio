## 安装 App

1. 下载并解压 App ZIP。
2. 把 `Codex Theme Studio.app` 移到“应用程序”或 `~/Applications`。
3. 首次启动如被 Gatekeeper 拦截，请在 Finder 中右键 App，选择“打开”；或在“系统设置 → 隐私与安全性”中批准。
4. 打开工作台，选择主题后开启皮肤。

此公开构建使用 ad-hoc 签名，未做 Apple 公证。项目不修改官方 Codex App、`app.asar` 或代码签名。

## 安装 Skill

解压 Skill ZIP 后，将 `create-codex-theme` 文件夹复制到：

```text
~/.codex/skills/create-codex-theme
```

重新打开 Codex 后即可使用：

```text
$create-codex-theme 帮我搜索一套墨绿色博物馆风格皮肤并安装
```

也可以直接描述新主题：

```text
$create-codex-theme 做一套黑紫青的赛博主题，主体放在右侧，现在就应用
```

Skill 会先搜索内置和本机已有主题。只有没有合适结果时才生成；默认只导入，不会重启 Codex，除非用户明确要求立即应用。

## 兼容性与声明

- 需要 macOS 13 或更新版本
- 需要已安装并至少启动过一次官方 Codex Desktop
- CDP 仅监听 `127.0.0.1`
- 公开内置的程序化主题不含第三方图片或角色素材
- 私人主题会保留在本机主题库中，但不会自动进入公开 Release
