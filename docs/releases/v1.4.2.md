# Codex Theme Studio v1.4.2

本版本新增主题资产刷新能力，解决应用保持运行时，新生成或新安装的皮肤不会立即出现在工作台的问题。

## 下载

- `Codex-Theme-Studio-macOS-v1.4.2.zip`：macOS 13+ 原生菜单栏 App
- `create-codex-theme-skill-v1.4.2.zip`：主题搜索与制皮 Skill
- `SHA256SUMS-v1.4.2.txt`：下载文件校验和

## 主要更新

- 主题库工具栏新增“刷新皮肤”按钮
- 菜单栏快速切换区新增刷新按钮
- 刷新时重新同步应用内置预设并扫描本机主题库
- 显示找到的新皮肤数量和主题库总数
- 搜索词与主题分类不会因刷新而重置
- 底部原“刷新状态”更名为“刷新运行状态”，与主题数据刷新明确区分

## 使用方法

生成或导入新皮肤后，打开工作台并点击“刷新皮肤”。主题会从以下位置重新读取：

- App 内置主题资产
- `~/Library/Application Support/CodexDreamSkinStudio/themes`
- 通过 `create-codex-theme` Skill 安装的本机主题

刷新只读取并同步主题资产，不会重启 Codex。选择新主题后，活动会话仍使用热切换。

## 安装提示

解压后把 `Codex Theme Studio.app` 放入“应用程序”或 `~/Applications`。公开构建采用 ad-hoc 签名、未做 Apple 公证；首次打开如被拦截，请在 Finder 中右键选择“打开”。
